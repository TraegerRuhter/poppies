## How to read the triage

Each idea in `ideas.md` is scored on:

- **Fit:** does it suit a one-or-two-person balloon studio on the Oregon coast,
  and the brand's restrained register (see `../website/decisions.md`)?
- **Effort:** S (an afternoon) / M (a week or so) / L (a project).
- **Payoff:** what it plausibly moves: bookings, price, reputation, or reach.
- **Needs her:** whether it can start without the owner's input.

Tiers: **Do now**, **Next**, **Explore**, **Parked**.
